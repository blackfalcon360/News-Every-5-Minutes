# News Every 5 Minutes

By: Black Falcon

Android radio app for the multilingual live news streams of https://www.replaynews.net/

- Package: `news.blackfalcon.jan`
- Play / Stop buttons, language dropdown with country flags (24 languages + Eco, Story, Sport)
- Scrolling headlines ticker (refreshes every 5 minutes)
- Background playback with a notification Stop button

## Description (243 characters)

Listen to live news radio in 24 languages with fresh headlines every 5 minutes. Pick your language with its country flag, tap Play and stay informed anywhere. Simple, fast and lightweight, with a scrolling headlines ticker from replaynews.net.

## Build the APK on GitHub

1. Create a new GitHub repository and upload all files of this project (keep the `.github` folder).
2. Open the **Actions** tab, run **Build APK** (it also runs on every push).
3. When it finishes, download **News-Every-5-Minutes-APK** from the run's Artifacts and install the APK.
